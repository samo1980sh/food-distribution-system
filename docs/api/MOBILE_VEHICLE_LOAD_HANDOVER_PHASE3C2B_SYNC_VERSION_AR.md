# Dynamic Phase 3C-2B-1 — نسخة مزامنة عهدة الحمولة

## الهدف

تحتاج عملية استلام العهدة عبر:

```text
POST /api/v1/operational/sync/push
```

إلى `base_version` خاص بسجل أمر التحميل. القراءة المباشرة السابقة كانت تعيد
بيانات الحمولة دون نسخة المزامنة، ولذلك لم يكن من الآمن إنشاء عملية Offline.

## العقد الجديد

يعيد مسار تفاصيل أمر التحميل:

```text
GET /api/v1/operational/vehicle-loads/{vehicleLoad}
```

الحقل:

```json
{
  "sync_version": "c:123"
}
```

كما تعيد نتيجة الاستلام المباشر النسخة الجديدة بعد نجاح العملية.

## النطاق

- لا تغيير على قائمة أوامر التحميل.
- لا تغيير على قواعد الاستلام أو الصلاحيات.
- لا Migration.
- لا حركة مخزون جديدة.
- لا تغيير على واجهات Flutter.
- النسخة تستخدم لاحقًا كـ`base_version` في Phase 3C-2B-2.
