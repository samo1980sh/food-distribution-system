# Dynamic Phase 3C-1 — الاستلام المباشر لعهدة الحمولة

## النطاق

هذه المرحلة تربط واجهة استلام العهدة المعتمدة في Flutter بمسار Laravel المباشر:

```text
POST /api/v1/operational/vehicle-loads/{vehicleLoad}/acknowledge
```

## قواعد العمل

- العملية متاحة فقط لأمر تحميل معتمد ومسند للمستخدم الحالي وما زال بانتظار الاستلام.
- يجب إرسال نتيجة لكل بند من بنود أمر التحميل.
- الكميات تدعم ثلاث منازل عشرية.
- فرق الكمية يحتاج ملاحظة على البند.
- حالة `discrepancy` تحتاج ملاحظة عامة، ويمكنها توثيق تلف مع كمية مطابقة عبر ملاحظة البند.
- عداد البنود المختلفة يشمل فروقات الكمية والمشكلات الموثقة مثل التلف.
- حالة `received` لا تسمح بفروقات كمية أو ملاحظات على البنود.
- تأكيد الاستلام يوثق الواقع الميداني ولا ينشئ حركة مخزون جديدة.

## قرار المزامنة Offline

لم تُفعّل المزامنة Offline في هذه المرحلة؛ لأن شاشة القراءة الحالية تعتمد REST ولا تملك
`base_version` المأخوذة من Sync Pull. تمت جدولة ذلك لمرحلة مستقلة بعد ربط Pull/Push
والتعارضات بقاعدة Drift.

لا توجد Migration في Laravel أو Flutter ضمن هذه المرحلة.
